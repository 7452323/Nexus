## 知识优先级（冲突时）

1. **用户指令最高**：用户明确说的设定、角色、情节 > 一切
2. **本项目文件次之**：本项目的设定文件、角色文件、世界观
3. **技能参考资料**：`references/` 下的文件
4. **通用网文理论**：三派方法论精华

---

## 铁律

1. **密码铁律**：生成过程中不要在对话里输出 Token/Key/密码
2. **粒度铁律**：人物一个一个文件、细纲一章一个文件、正文直接写文件不输出对话
3. **字数铁律**：长篇每章 ≥ 8000 字（断章线以上密度）；短篇每节 ≥ 1000 字
4. **禁用符号铁律**：正文禁用 `……` / `——` / `—` / `--`，用句号逗号beat断开
5. **否定优先铁律**：严禁先否定再肯定的翻转句式，直接写肯定
6. **元信息铁律**：正文里不出现"第X章""上一章""伏笔""读者"这类元叙事词
7. **章节尾禁止升华**：用动作/对话/悬念收尾，不用大段抒情
8. **装逼不主动证明**：少让主角说"我很强"，多让环境/他人/时间告诉社会
9. **降智绝不主动**：反派不走降智套路，冲突要真实可代入
10. **爽点宁过勿缺**：网文要强噱头强爽强情绪，不温吞保守

## 阶段3：大纲生成原则

1. **五级展开**：1级统领全书 → 2级故事线 → 3级情节单元 → 4级推演 → 5级具体过程
2. **三级结构判断**：
   - 一级（单元剧串联）：网文大忌，上限有限
   - 二级（套娃升维）：每卷一个故事，每部分又含小故事
   - 三级（连锁编织）：卷卷互联，所有情节互相作用（大师级）
3. **章纲要素**：本章目标 → 冲突 → 关键 beat 列表 → 本章钩子 → 伏笔操作
4. **分块生成**：章数多时分块生成（每块10-20章），保持上下文连贯

## 阶段4：章节创作原则

### 三维度揉进
每个子事件必须同时包含：
1. **发生**：事件从何而来（1-2句叙事）
2. **感知**：主角感官注意到什么（≥1种不同感官）
3. **反应**：身体如何回应（具体动作，可含极短心理定格）

### 单章写作流程
1. 读取上下文（大纲 + 上一章 + 角色状态）
2. 确认本章节奏和情绪目标
3. 写正文（三维度揉进 + Gate 去AI味）
4. 写完检查：章尾钩子 → 爽点是否到位 → 字数达标

### 写完后必检
- [ ] 字数达标
- [ ] 章尾有动作钩子，无升华抒情
- [ ] 无禁用符号（……/——/--）
- [ ] 无先否定再肯定翻转句式
- [ ] 无元叙事词（"第X章""上一章"等）
- [ ] 无万能比喻（"像潮水般""如闪电般"）
- [ ] 对话匹配角色语言风格
- [ ] 无God Mode / 解释腔

## 阶段5：质量审查标准

| 维度 | 评分标准 |
|------|---------|
| 代入感 | 视角锁死、身体反应真实、细节具体 |
| 节奏 | 起承转合清楚、起伏合理、无拖沓 |
| 信息密度 | 每秒有效信息量、非注水内容 |
| 去AI度 | 0处禁用符号、句式多样、无万能比喻 |
| 情绪弧线 | 每节至少拨动一次读者情绪弦 |

## 高级技法速查

| 技法 | 适用场景 |
|------|---------|
| 信息差拉期待 | 制造悬念、增加阅读动力 |
| 震惊波及链 | 配角周围人感知到装逼事件后连锁反应 |
| 以退为进拉期待 | 主角吃亏/退步时注入希望 |
| 首尾道具呼应 | 贯穿道具三次出现，意义逐次翻转 |
| 一伏千里 | 答案从开局就给，读者到最后才发现 |
| 二级结构化装逼 | 一级震惊 + 二级震惊（有递进关系） |
