## 通用模板

### 8节点长篇结构

每卷8个节点，每卷约 30-50 章，目标 10-15 万字/卷。

```
节点1：开局定调 + 核心冲突引入（2-4章）
节点2：困境加深 + 金手指觉醒/获得（3-5章）
节点3：首次小胜 + 反派/对手反馈（3-5章）
节点4：遭遇挫折/阴谋暴露（3-5章）
节点5：隐忍/觉醒/友情支线推进（3-5章）
节点6：二次崛起 + 大的爽点释放（4-6章）
节点7：最终对抗前奏 + 多方势力汇聚（3-5章）
节点8：高潮决战 + 收束+钩子（4-6章）
```

### 压缩三幕短篇结构（≤5万字）

```
第一幕（30%）：触发事件 → 目标确立 → 尝试失败
第二幕（50%）：升级困境 → 至暗时刻 → 顿悟/反杀铺垫
第三幕（20%）：高潮对决 → 真相揭示 → 余韵收束
```

## 男频12类

### 1. 玄幻升级流
- **核心爽点**：升级突破、越阶打脸、秘境探宝、装逼收小弟
- **标准开局**：废物/被废 → 金手指觉醒 → 打脸第一个看不起他的人
- **金手指类型**：系统/老爷爷/血脉觉醒/混沌神器
- **换地图节奏**：小域→大陆→上界→神域（每30-50万字换一次）
- **节奏要点**：每3-5章一个小爽点，每20-30章一个大高潮

### 2. 都市鉴宝/神医
- **核心爽点**：捡漏暴富、打脸势利眼、治病救人+人脉积累
- **获得感来源**：知识碾压（别人看走眼、主角识真货）
- **节奏要点**：每章必须有一个爽点

### 3. 历史穿越/架空
- **核心爽点**：现代知识碾压古人、改革制度、军事谋略
- **核心梗**：蒸汽机改朝/火药制敌/商战制国
- **写法要点**：政治线+军事线+日常生活线三线交织

### 4. 仙侠/修真
- **核心爽点**：大道之争、渡劫飞升、万族争锋
- **独特点**：寿命竞赛（别人活几千年被天才几百年追上）
- **升级体系**：炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫

### 5. 都市霸总/商战
- **核心爽点**：商业碾压、股市翻盘、家族遗产
- **节奏**：装逼打脸周期短（3-5章一轮）
- **写长手段**：商战升级（个体户→公司→集团→跨国财阀）

### 6. 诸天/无限流
- **核心梗**：穿越各个副本（电影/小说/游戏世界）收集资源
- **爽点来源**：信息差（知道剧情走向）+ 能力碾压（从副本带回能力）
- **写法要点**：副本之间用"主神空间"串联，副本内独立成章

### 7. 诡异/克苏鲁
- **核心情绪**：恐惧 → 求存 → 真相逼近
- **氛围要求**：开篇即反常，每章堆叠不安感
- **写法要点**：信息不全描写（不要全知），读者和主角同步发现

### 8. 荒野/星际/科幻
- **核心爽点**：科技碾压/生存扩张/宇宙版图
- **写法要点**：硬核设定 + 软性情感，每设定必有爽点出口

### 9. 游戏/电竞
- **核心梗**：重生/穿越/满级玩家进新服
- **爽点来源**：隐藏职业/唯一任务/操作碾压
- **节奏**：副本→PK→赛事循环

### 10. 御兽/召唤
- **梗**：御兽师 + 魂力等级系统
- **核心爽点**：隐藏进化路线、极品兽宠
- **写法**：兽宠的忠诚+人宠互动拉长感情线

### 11. 无敌流
- **唯一铁律**：主角不走拖拉，碾压要快、准、狠
- **爽感来源**：信息差（不知道主角身份的人看不起主角）
- **写法要点**：视角转换（通过他人感知主角的强大）

### 12. 系统/签到流
- **梗**：完成任务获得奖励/每日签到/挂机
- **节奏**：每单都是独立小故事，串联为大长篇
- **写法要点**：单元剧模式

## 女频8类

### 1. 古言/宫斗
- **核心爽点**：智商碾压后宫、夺嫡争权、隐藏身份
- **写法要点**：女主隐忍→崛起→横扫
- **节奏**：每一个小场景都要信息差（女主知道敌方不知道）

### 2. 现言/甜宠
- **核心爽点**：狗粮+事业双收
- **爱情线四阶段**：相识→误解→靠近→危机→在一起
- **节奏要快**：甜虐交替，虐不过3章

### 3. 重生/逆袭
- **梗**：重生归来→复仇→事业爱情双收
- **爽点核心**：上一世仇人这一世被打脸
- **写法要点**：前世惨状 → 重生触发 → 反杀开始

### 4. 穿书/穿漫画
- **梗**：穿成炮灰/反派→自救→改写结局
- **爽点**：遵循原剧情的"恶意利用"（知道剧情走向反套路）
- **核心张力**：天道/剧情走向的修正阻力

### 5. 修仙/仙侠（女频侧）
- **核心梗**：升级+感情线绑定
- **写法**：事业线+爱情线双线交织，互为驱动力

### 6. 校园/青春
- **核心情绪**：暗恋→明恋→成长
- **亮点**：双向奔赴/破镜重圆/温情节日

### 7. 追妻/火葬场
- **结构**：错过→后悔→追妻→甜蜜/遗憾
- **爽点**：前期虐女主后期虐男主
- **铁律**：追妻要足够难，代价要足够大

### 8. 救赎/病娇
- **核心情绪**：禁忌+拉扯+身份落差
- **写法**：边缘人格+极限拉扯，心理描写比外部动作更重要
- **风险**：易踩红线，需精准把握度

## 狗粮文循环套路

1. **矛盾产生**：误会/强势/隐瞒
2. **一方低头**：男的哄/女的让步（女频多见）
3. **亲密升级**：拥抱/接吻/暧昧场景
4. **外部阻碍**：家族反对/白月光/情敌
5. **克服阻碍**：实力证明/真相暴露
6. **甜蜜升级**：同居/结婚/升级亲密
7. → 回到步骤1（换一个新的矛盾点）

## 爱情线四阶段

| 阶段 | 名称 | 标志 | 写法提示 |
|------|------|------|---------|
| 一 | 心动期 | 目光追随、心率加速 | 含蓄，表情和微动作 |
| 二 | 暧昧期 | 试探、误会、亲密张力 | 制造身体接触的理由 |
| 三 | 危机期 | 外部压力+内部矛盾 | 给足理由不在一起 |
| 四 | 确认期 | 表白/同居/公开 | 确认后撒糖持久 |

## 男频极简爱情线（高性价比写法）

男频不需要复杂爱情线，给女主一个**功能性人设**即可：

- **功能A**：治疗/辅助 → 男主角受伤/任务时出场
- **功能B**：提供情报/资源 → 男主情报来源
- **功能C**：制造误会冲突 → 推动剧情转折

写作要点：
- 女主独立有魅力不弱智
- 互动简洁有张力（三句之内有信息推进）
- 不能因为感情线断爽点节奏

## 事业线×爱情线融合检查

| 检查项 | 标准 |
|--------|------|
| 事业线爽点 | 是否每章至少一个 |
| 爱情线推进 | 每次互动是否带来新信息 |
| 双线交叉 | 感情推进是否为事业线的驱动力 |
| 危机利用 | 外部危机是否用来加深感情 |
| 节奏比重 | 男频事业≥70%，女频爱情≥50% |
