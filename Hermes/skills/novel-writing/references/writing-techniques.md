## 三维度揉进法

每个子事件必须同时包含三个维度，如同麻花拧在一起，**不按维度分段写**：

| 维度 | 定义 | 字数占比 | 方法 |
|------|------|---------|------|
| **发生** | 事件从何而来 | 1-2句 | 具体叙事，带细节 |
| **感知** | 主角感官注意到什么 | 至少1个不同感官 | 视觉/听觉/触觉/嗅觉/味觉 |
| **反应** | 身体如何回应 | 具体动作 | 身体动作、面微表情、心跳呼吸 |

### 三维度揉进范例

```markdown
❌ 错误写法（分段堆叠发生→感知→反应）：

门被踹开了。
他听到一声巨响。
他吓了一跳，心脏猛跳。

✅ 正确写法（三维度揉进同一段）：

门被踹开的瞬间，木屑擦过他脸颊。左耳嗡的一声，心跳撞到了嗓子眼。
```

### 子事件连接

- 详写的子事件合计 ≥ 150 字
- 过场/连接类 1-2 句带过
- 不是每个子事件平均用力

### 画面分段规则

- 按**新动作/新物件/新信息/新对话**断段，不按维度断段
- 手机阅读密度：按动作/信息变化断段
- 读起来卡 = 逗号太长 = 需要拆段
- 连续碎段像提纲 = 合并同镜头内的相邻句
- 正文相邻段落之间只允许一个 `\n`，不出现空行或 `\n\n`

## 镜头式写作法

### 三机位法

| 机位 | 作用 | 字数比 | 何时用 |
|------|------|-------|--------|
| 近景 | 身体动作、微表情、物件细节 | 40% | 对话和日常生活 |
| 远景 | 环境氛围、空间关系、全景 | 20% | 场景揭幕/氛围营造 |
| 旁白 | 内心独白、闪念、情绪反应 | 10% | 关键决策点/闪回 |
| 留白 | 信息省略、读者参与推理 | 30% | 不需要解释的地方 |

### 从影视学技巧

1. **慢镜头/关键时刻**：为读者"重播"一个决定性的动作
2. **快切**：多条信息快速堆叠（紧张/混乱场景）
3. **长镜头**：无切换持续叙述（对话场景/追逐）
4. **反应镜头**：先写旁观者反应，再写事件本身（震惊传播）

## 节奏控制

### 基础节奏型

```
缓 → 起 → 急 → 爆 → 缓 → [循环]
```

### 网文节奏变体

| 节奏型 | 描述 | 适用 |
|--------|------|------|
| 推波型 | 紧张逐渐攀升，一波高于一波 | 战斗/升级 |
| 断裂型 | 突然插入新事件打断当前节奏 | 反转/意外 |
| 平行型 | 两条线交替，紧张和平缓穿插 | 双线叙事 |
| 沉淀型 | 高潮后的情感缓冲 | 大结局前 |

### 段落节奏公式

- **情绪beat**用短句
- **过场/过渡**用长句（加速流速）
- **高潮/反转**用骤短句
- **沉淀/思考**放慢句速
- 禁忌：通篇同长度句

## 一动一静节奏法

**动作段**后接**静止感知段**，制造呼吸感：

```
动作A → 静止段（内心独白/环境细节/闪回） → 动作B
```

### 应用场景

- 战斗后接一段环境/感悟
- 大事件后接一段日常生活
- 对话交锋后接一段内心反应

## 疏密分配

### 三种力度

| 力度 | 描写量 | 场景 |
|------|-------|------|
| **密（详写）** | 单事件 ≥ 150字 | 关键爽点、反派对决、转折点 |
| **中（一般）** | 单事件 50-100字 | 推进剧情的必要场景 |
| **疏（略写）** | 1-2 句带过 | 过场/赶路/时间流逝/不重要日常 |

### 疏密节奏

```
密 → 疏 → 中 → 密 → 疏 → 密 [高潮]
```

禁忌：通篇密（读者累）、通篇疏（读者觉得水）

## 贯穿道具三次出现

每个重要物件必须出现 **3 次**，意义逐次翻转：

| 次数 | 出现位置 | 作用 | 意义 |
|------|---------|------|------|
| 第1次 | 前半段 | 引入/伏笔 | 表面功能 |
| 第2次 | 中段 | 再次垫高 | 暗示深层含义 |
| 第3次 | 高潮/结局 | 引爆/余韵 | 意义完全翻转 |

### 范例

```
道具：一枚普通铜钱
第1次：主角用它买了碗面（日常带入）
第2次：主角发现铜钱背面有暗记（暗示身份）
第3次：铜钱是号令天下的信物（意义翻转）
```

## 小节密度诊断

每写完一小节，用以下 5 项检查：

| 检查项 | 标准 | 命中即修 |
|-------|------|---------|
| 信息密度 | 每500字至少1个新信息点 | 纯描写无信息要补事件 |
| 冲突密度 | 每小节至少1个冲突点（内心/人际/外部） | 无冲突=无张力 |
| 情绪密度 | 每节至少拨动一次读者情绪弦 | 情绪温吞要加力 |
| 钩子密度 | 每小节末尾至少1个向下推动力 | 平收无悬念要加钩子 |
| 信息过载 | 单段不超4个新信息点 | 过载要拆分到其他段 |

## 黄金三章写法

### 前 100 字事件密度 ≥ 3

事件密度 = 读者在前100字里能感知到的信息事件数量。

```
例：
"沈渊被铁链吊在刑架上。三天。肉烂见骨。
他知道是谁送来的这根链子。林婉儿。他未婚妻。
昨夜她端的酒，他喝了。"

前100字三个事件：被囚禁、伤重、认出凶手
```

### 开头三大基点

| 基点 | 写法 | 效果 |
|------|------|------|
| 即视冲突 | 开场即进入冲突 | 拉紧张 |
| 情感钩 | 一个让人共情的情感点 | 拉代入 |
| 悬念点 | 一个未解之谜 | 拉期待 |

## 开篇技巧九种

| 类型 | 写法 | 适用 |
|------|------|------|
| 冲突前置 | 开场即战斗/危局 | 爽文 |
| 信息差钩 | "他还不知道，这杯酒是毒酒" | 悬疑 |
| 反常行为 | "少爷居然笑了，在他灭门之后" | 重生/悬疑 |
| 超自然身份 | "自己手上出现了金色纹路" | 玄幻/都市 |
| 灵魂旁观 | 主角灵魂旁观自己的葬礼+发现真相 | 重生 |
| 悬念句 | "那扇门后面，是他死过三次的地方" | 悬疑/诡异 |
| 代入式提问 | "你有没有想过，最亲的人可能在害你？" | 现实/悬疑 |
| 重生反常 | "他在20XX年醒来，回到了那一天" | 重生/穿越 |
| 替嫁被弃 | 经典开场（女频极具杀伤力） | 古言/重生 |

| 类型 | 写法 | 适用 |
|------|------|------|
| 余韵式 | 安静细节，言有尽意无穷 | 情感章 |
| 呼应式 | 和第N章形成对照 | 大结局 |
| 开放式 | 故意留白 | 转折后/悬念 |

## 代入感构建法

### 以身入局四步法

1. **明确身份**：主角是谁（用细节带入，不用旁白介绍）
2. **身体感受**：此刻身体在哪里、什么状态、什么感官
3. **当下目标**：此刻要做什么（立刻的具体目标）
4. **障碍感知**：什么在妨碍他

### 共情三层次

| 层次 | 定义 | 写法 |
|------|------|------|
| 认知共情 | "我理解这件事" | 角色行为逻辑清晰 |
| 情绪共情 | "我替TA着急" | 情绪信号强烈到读者无法忽视 |
| 身体共情 | "我感觉到疼/爽" | 感官细节让读者身体反应 |

### 情绪缺口与共情放大

读者共情 = 期望与现实的落差 → 用"期望 → 落空 → 低谷"制造共情

### 信息差拉期待技术

读者知道但主角不知道 → 读者替主角着急
主角知道但反派不知道 → 读者期待反派被打脸
三方互相不知 → 三方汇聚时的碰撞期待

## 写作四要点

### 要点一："然后呢"原则

每段话都要让读者产生"然后呢？"的期待。如果一个段落的答案是"就这样"，删掉它。

### 要点二：间接描写

用对话/行为/物件间接展示性格，不用旁白总结：

```
❌ "他胆小怕事"
✅ "他听到脚步声就绕路走"
```

### 要点三：情弦理论

锁定目标读者的核心情感弦，每节至少拨一次。
男频常见情弦：被认同、被尊重、向上爬的渴望。
女频常见情弦：被理解、被保护、被看见。

### 要点四：宏观微观一体把控

每5-10章回顾一次：
- 微观：这一章/这一节是否符合情绪节奏
- 宏观：是否偏离大纲主线/是否有设定不一致
