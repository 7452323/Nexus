## 主角设计法（三方驱动）

### 核心驱动力三角

| 层级 | 名称 | 定义 | 示例 |
|------|------|------|------|
| 第一层 | 表面追求 | 主角自己说出来的"我要XX" | "我要成为最强" |
| 第二层 | 深层渴望 | 主角没说出来但行为暴露的"我真正要XX" | "我要被人看得起" |
| 第三层 | 灵魂需求 | 主角自己都没意识到的终极驱动力 | "我想证明我不该出生在这个家" |

**三者关系**：
- 表面追求 ≠ 深层渴望（制造角色复杂性）
- 深层渴望 ≠ 灵魂需求（制造角色弧）
- 灵魂需求的觉醒是角色成长的高潮点

### 主角必须填写的字段

```
姓名：
年龄：
身份：

表面追求（口头目标）：
深层渴望（行为暴露）：
灵魂需求（潜意识驱动）：
恐惧：
弱点（可被利用）：
嘴癖/口头禅：
标志性动作（读者记忆点）：

初始状态：
最终目标状态：
成长弧线怎么走：
```

### 反派的塑造铁律

反派不能降智。反派应该：
- 有合理动机（不是"我就是坏"）
- 和主角的冲突有必然性（不是强行对立）
- 在主角到来之前的逻辑里是"胜利者"
- 有高于主角某方面的优势（不能全方面废物）

## 配角脸谱化

### 标签化三要素

| 维度 | 必须项 | 示例 |
|------|-------|------|
| 外貌标志 | 一眼识别 | "独眼""胖""红发" |
| 性格标签 | 一个词概括 | "妻管严""好奇宝宝""笑面虎" |
| 功能定位 | 主角团队中作用 | "吐槽+治疗""智慧和决策""搞笑+悲剧" |

### 配角差异化对照

相邻角色绝对不能互换。每新增一问配角，先问：
1. 这个角色的标签是什么？
2. 和现有配角的功能是否重叠？
3. 是什么让读者记住他？

## 角色语言风格档案

每个重要角色必须有一个语言风格档案：

```
角色名：
句式特征（长短/用词/修辞）：
口头禅：
独处时说话方式：
压力下说话方式：
撒谎时的破绽：
对上级 vs 对下级的差异：
对伪装身份时的不同：
```

**写作检查**：写完对话后，遮住角色名，读台词——能不能通过台词认出来是谁说的？

## 角色状态追踪

每章结束时必须更新主角（和重要配角）的状态：

```markdown
## 角色状态表

### [主角名]
- 身体状态：（未受伤/轻伤部位/重伤状态/特殊状态如狂暴）
- 情绪状态：（当前核心情绪词）
- 实力等级：（当前等级/是否有突破迹象）
- 持有物品：（关键道具变化）
- 关系变化：（和谁的关系发生了变化）
- 待解决目标和线索：

### [配角A名]
- 身体状态：
- 情绪状态：
- 与主角关系变化：
- 已知信息：
```

**状态树维护**：可用一个字典格式维护角色之间的状态关系，每次互动后更新。

## 角色关系图构建

### 三种关系维度

1. **利益关系**：合作/竞争/利用
2. **情感关系**：爱/恨/嫉妒/崇拜/愧疚
3. **认知关系**：知道/误解/未知

### 关系变化驱动剧情

剧情推进本质是**角色关系的变化**。每次互动至少带来一个维度上的变化。

### 反派主角关系三阶段模型

| 阶段 | 特征 | 操作 |
|------|------|------|
| 一：暗流 | 间接冲突，互相试探 | 写信息博弈和势力对比 |
| 二：正面对抗 | 冲突公开化，大矛盾爆发 | 写战斗/算计/算计失败 |
| 三：不死不休 | 双方必须彻底击败对方 | 写阴谋/高潮/解决 |

## 后宫文女主人设设计法

### 核心思路

每个女主必须满足一个**男性幻想原型**。叠加多个原型会稀释。

### 核心原则

1. 独立人格：不是附属品
2. 不可替代功能：男主需要她的某种能力/存在
3. 温水煮青蛙：从"不感兴趣"到"不可或缺"

### 设计模板

```
姓名：
标签（核心记忆点）：
与男主关系类型（青梅竹马/天降/敌对转化/师徒等）：
口头禅/特征动作：
对男主态度变化轨迹：
关键时刻的贡献（不可替代事件）：
```

## 高情商/聪明人角色塑造法

### 三种写法

| 层次 | 写法 | 特征 |
|------|------|------|
| 浅层 | 说话留三分、不说满 | 让人感觉"这个人不好惹" |
| 中层 | 预判对方意图、抢先一步布局 | 让人感觉"他什么都算到了" |
| 深层 | 不解释、让读者后知后觉 | 让人回看时发现"原来他早就知道" |

### 聪明人的禁忌

- 不要让他主动解释计划（要通过行动让读者看清）
- 不要让他永远正确（偶尔失算更真实）
- 不要让他傲慢高高在上（让人讨厌）

## 常见毒点

| 毒点类型 | 表现 | 规避方法 |
|---------|------|---------|
| 圣母心 | 主角原谅不可原谅之事 | 动机合理、读者理解 |
| 送女 | 女主被送/转赠/交易 | 绝对禁区 |
| 绿帽 | 女主和他人有染 | 绝对禁区 |
| 虐主过度 | 主角一直被压无法喘气 | 每次压制后面跟着更强烈的反杀 |
| 工具人配角 | 配角纯服务、无独立人格 | 给配角小目标和个人弧 |
| 逻辑崩坏 | 设定前后矛盾 | 用角色状态追踪+设定checklist |
| 文青式独白 | 大段无情绪的文艺描写 | 删，用动作代替 |
| 作者代入 | 作者通过角色之口说教 | 角色不需要替作者思考 |
| 节奏失控 | 30章无大事件 | 每10章一个兴奋点 |
| 降智光环 | 反派集体变蠢 | 反派智商始终在线 |
