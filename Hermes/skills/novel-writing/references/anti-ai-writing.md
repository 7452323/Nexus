## AI味的八种典型表现

| 模式 | 表现 | 修正方向 |
|------|------|---------|
| 1. 空洞开头 | "这是一个关于XX的故事" | 直接切入场景 |
| 2. 过度抽象 | "他感到一股复杂的情绪" | 具体身体反应 |
| 3. 解释腔 | "之所以…是因为…" | 让读者自己推理 |
| 4. 上帝视角 | 叙述者跳出角色当下解释 | 锁死角色限知视角 |
| 5. 公式化句式 | 连续五段"SVO+描写"同构 | 打散句式 |
| 6. 万能比喻 | "像潮水般/如闪电般" | 生活化/角色化比喻 |
| 7. 作者说教 | "这告诉我们…" | 删掉，让情节自己说 |
| 8. 安排感/刻意感 | "像XX一样/这出戏她看过" | 删除叙述者评论 |

## 7 Gate去AI味检查

写完每章依次过7个Gate：

### Gate A：禁用词替换

命中即替换，不商量：

```
禁用词                      替换方向
─────────────────────────────────────────
命运齿轮              → 用具体的因果描写
如潮水般              → 用具体感受
仿佛春风              → 用触觉/视觉细节
心猛地一沉            → 心跳漏了一拍+具体身体反应
眼眶泛红              → 喉头发紧/视线模糊
仿佛下定了决心        → 写动作
他不知道的是          → 删！直接讲他不知道的事
殊不知                → 删！
多年以后              → 删！由他回忆呈现
演得真好              → 删！安排感禁句
像下定了某种决心      → 删！烂大街句式
一股复杂的情绪        → 具体是哪一种情绪？写出来
他终于明白            → 用动作或环境暗示
```

### Gate B：句式去套路

- 连续排比三段以上→打散
- 刻意对称句式→自然化
- 空洞抒情→具体细节

### Gate C：心理描写外化

默认情绪词→身体状态：

```
❌ "她很愤怒"     ✅ "手指甲掐进肉里"
❌ "他紧张"       ✅ "喉结滚了一下"
❌ "愧疚涌上心头" ✅ "不敢看她"
```

### Gate D：节奏打碎

- 长句拆短
- 同构句打散
- 按新动作/新物件/新信息/新对话断段
- 连续碎段像提纲→合并

### Gate E：对话去腔调

所有角色同一语气→差异化：
1. 检查每个角色的说话节奏/用词
2. 确认角色对话风格与语言风格档案匹配
3. 对话标点=权力位置+情绪匹配

### Gate F：结尾去升华

大段抒情收尾→安静细节收尾

### Gate G：去解释腔/上帝感

删一切跳出角色当下的解释：
- 删除：之所以/原来/这意味着/她不知道的是/殊不知/多年以后
- 因果与定性留给读者从动作对话里自己拼

## 系统性去AI三遍法

### Pass 1：去泛化

扫描所有抽象词，替换为具体细节：

| 抽象词 | 替换 |
|--------|------|
| "悲伤" | 具体的身体反应（手抖/说不出/站不稳） |
| "愤怒" | 具体行为（摔东西/沉默/咬牙） |
| "紧张" | 物理信号（出汗/咽口水/心跳） |
| "物品" | 具体的物品名字 |
| "地方" | 具体的地点 |

### Pass 2：去书面化

书面腔→口语/动作：

| 书面腔 | 口语化 |
|-------|-------|
| "心中五味杂陈" | "说不清是什么滋味" |
| "不禁陷入沉思" | "他没说话" |
| "目光如炬" | "直直盯着" |

### Pass 3：回自然感

注入停顿、犹豫、矛盾和口语感：
- 加入身体反应的中断
- 加入思绪的碎片
- 加入真实口语中的省略

```

仿佛梦境      → 写具体的感官异常

世界都亮了    → 写具体色彩/光感
```

## 展示而非陈述原则（Show Don't Tell）

### 陈述 vs 展示对照

| 陈述 | 展示 |
|------|------|
| "他很紧张" | "他把衣角攥出了褶子" |
| "她很美" | "他多看了一眼" |
| "他很愤怒" | "齿缝里挤出一个字" |
| "这是危险的地方" | "他踩到一根断骨" |
| "她很伤心" | "她没说完那句话就转身" |

### Show的三要素

1. **具体细节**（不是泛化词）
2. **感官证据**（读者能感知到）
3. **不直接说破**（让读者自己推断情绪）

### 何时Tell可以

1. 过场信息快速推进
2. 纯过渡段
3. 读者不需要太深感知的次要内容
4. 节奏需要加速时

## 文风一致性

### 文风指纹要素

每次续写前确认：

| 要素 | 检查项 |
|------|--------|
| 句长带 | 短句比例/中句/长句/平均句长 |
| 标号节奏 | 句号、逗号、问号、感叹号分布 |
| 文白比例 | 多少书面语/口语 |
| 空间密度 | 段落长度、换行频率 |

### 文风漂移诊断

写完一章后于对标书对比：
1. 逐章读3-5章，体感文风差异
2. 关键词出现频率对比（口癖/特定词）
3. 句式复杂度变化

### 防漂移规则

- **不可每章递减复杂度**（即"越写越碎"）
- **句长不可越来越短**
- **文风漂移即重写**

## 正文格式硬规范

1. 正文相邻段落之间只允许一个 `\n`，不出现空行
2. 对话独立成行
3. 对话标签不强制变换（普通"说"可保留）
4. 不用 `---` 分隔正文片段
5. 引号风格默认半角双引号
6. 正文标题：长篇 `## 第X章 章名`

---

## 元信息污染检查

正文逐段扫描以下正则词，命中即改写：

```
/第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者/
```

只有以下例外可以保留：
- 故事内角色正在阅读/讨论"第X章"文字
- 角色是真实的作者/读者身份并谈论读者身份
