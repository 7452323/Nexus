## 对话的本质

对话是角色的**武器和面具**——每个角色都在对话里达到某种目的。

对话必须同时完成两件事：
1. 推进情节/信息（表层）
2. 暴露/隐藏人物真实想法（深层）

---

## 对话三禁忌

### 禁忌一：信息倾倒

```
❌ "你听我说，三年前那场大战，我们五兄弟结义，
结果老大背叛了我们，害死了老二老三，
老四失踪，现在只剩我一个人了。"

✅ 对话：
"你还记得那场大战？"他问。
"……别跟我提那件事。"
"老大叛了。你知道。"
"知道。老二老三老四都知道。他们死了，只剩我知道。"
```

### 禁忌二：问答式对话

```
❌ "你是谁？" 
"我是XXX。" 
"你来干什么？" 
"我来找你。" 
"找我做什么？"

✅ 有情绪、有目的、有潜台词的对话
```

### 禁忌三：说话不匹配场合

高压/生死/悲痛场景里不能有搞笑担当的玩笑话，除非崩溃性反应。

## 潜台词设计

### 三层对话结构

| 层级 | 定义 | 例 |
|------|------|---|
| 表层 | 角色说的话 | "你吃过了吗？" |
| 中层 | 角色想表达但不明说的 | "我在关心你" |
| 深层 | 角色真正的意图（可能自己都没意识） | "我想挽留你别走" |

### 写出潜台词的方法

1. 给角色一个当下的真实目的（不是"推进剧情"）
2. 让角色**不全说真话**
3. 用身体动作和短句替代直白说明
4. 让对方的反应暴露了潜台词

```
例：
表层："你今天要去哪？"
中层："我想知道你是不是要离开我"
深层："我不想让你走但说不出口"
```

## 权力博弈与语气

### 对话中的权力位置

| 位置 | 表现 | 写作提示 |
|------|------|---------|
| 高位 | 少说、问句多、慢节奏 | 强势者多听少说，偶尔质问 |
| 低位 | 多解释、重复确认、快语速 | 弱势者多解释，有求于人 |
| 平等 | 互相挑战、调侃 | 熟人之间的损和互怼 |

### 语气与权力对照

| 关系 | 语气特征 |
|------|---------|
| 上下级 | 职位低的先开口；请示式语言 |
| 敌对 | 简短、带刺、信息密度高 |
| 暧昧 | 试探、反问、故意曲解 |
| 亲密 | 吐槽、打断、省略主语 |

## 信息嵌入与信息倾倒

### 设定信息嵌入法

不要角色亲口说出设定，而是：

| 方法 | 例 |
|------|---|
| 冲突中暴露 | A攻击B时发现B用的是"五岳宗剑法" |
| 物件展示 | 他掏出腰牌"内门·第七" |
| 第三人谈论 | "听说他们宗门上月刚被天门宗端了" |
| 主角的内心闪回 | 这个标记——三年前掌门身上的那个 |

### 信息倾倒的判断标准

如果一个角色在说"我应该知道但你想让读者知道的信息"= 信息倾倒。

## 场合匹配

### 六种典型场合的对话规则

| 场合 | 规则 |
|------|------|
| 紧张/对峙 | 简短、不完整、频繁身体描写插入 |
| 亲密/暧昧 | 停顿多、眼神多、语义跳跃 |
| 日常/插科打诨 | 可以碎嘴、可以夸张 |
| 高潮/真相揭露 | 长段爆发、情绪激烈 |
| 悲痛 | 不完整、停顿多、反应错位 |
| 朝堂/ | 正式、有节制、每句话有目的 |

### 高压场景禁止

高压/生死场景里的以下写法：
- 搞笑担当讲笑话
- 轻快配角插科打诨
- 过多无意义的寒暄

处理：收敛成"短冷带情绪重量的反应"。

## 角色声音差异化

### 三档音量设置

| 角色类型 | 说话方式 | 例 |
|---------|---------|---|
| 主角 | 独特但不抢戏 | 有自己的节奏和决断 |
| 配角 | 功能性+记忆点 | 每句话带特征 |
| NPC | 大众化 | 不过度描写 |

### 语言风格档案对照

每个配角记录：
- 句式平均长度 (<10字 = 紧张型，>30字 = 讲述型)
- 口头禅/固定用语
- 对上位者的差异
- 对下位者的差异

## 逐句情绪反馈

每句对话应该回应对方上一句的**情绪**：

| 反馈类型 | 特征 | 话术 |
|---------|------|------|
| 承接 | 接纳对方情绪 | "你说得对，但是…" |
| 偏转 | 不讲道理只讲情绪 | "你说完了？我说我的。" |
| 升级 | 情绪冲突加剧 | "你有种再说一遍。" |
| 退缩 | 情绪压制/让步 | "……行。" |

**没有反馈的对话 = 问答式 = 信息倾倒。**

## 对话标点规范

| 场景 | 正确 | 错误 |
|------|------|------|
| 质问 | ？ | 多个？？？ |
| 感叹 | ！（少量） | 多个！！！ |
| 犹豫 | 用动作/beat断开 | 用"……" |
| 打断 | 用短句/新行 | 用"——" |
| 拖长 | 用"即——嗯…"描写 | 长串标点 |

## 对话格式规范

```
正确：
"你走。"他说。
她没动。

"我在跟你说话。"
"听见了。"

错误：
"你走，"他说，"不要再出现了！"
"我不要！"她哭喊，"我不能没有你！"
"你以为我会心软吗？！"他咆哮。
```

格式要点：
1. 对话独立成行
2. 对话标签（他说/问/喊）放在同一行
3. 两个人的对话之间不远隔段落
4. 不用连续感叹号/问号/重复标点
5. 不用 "……" 表示犹豫/未尽
6. 不用 "——" 表示打断
