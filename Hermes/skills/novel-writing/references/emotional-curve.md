## 情绪设计总纲

### 读者阅读的情绪路径

```
开头：期待（金手指/冲突触发）
      ↓
发展：紧张（困境加深）
      ↓
升级：压抑/愤怒（反派压迫）
      ↓
释放：爽（反杀/打脸/突破）
      ↓
过渡：平和/反思
      ↓
循环回到开头
```

### 情绪和弦 vs 情绪噪音

- **和弦**：符合当前情节的情绪表达（✓）
- **噪音**：和情节基调矛盾的情绪表达（✗）

## 情弦理论

### 定义

**情弦** = 目标读者内心最敏感的一根情感线，每节至少拨动一次。

### 各题材情弦参考

| 题材 | 核心情弦 | 次要情弦 |
|------|---------|---------|
| 玄幻升级 | 被尊重/变强渴望 | 同门情谊、装备贪婪 |
| 都市鉴宝 | 知识优越感/财富积累 | 美女环绕、打脸装逼 |
| 历史穿越 | 智慧碾压/权力欲 | 改革快感、预知命运 |
| 诸天无限 | 信息差优越/生存恐惧 | 资源收集紧迫感 |
| 现言甜宠 | 被宠溺/心动感 | 嫉妒、保护欲 |
| 古言宫斗 | 智商碾压/步步为营 | 隐忍、韬光养晦 |
| 重生逆袭 | 复仇快感/改写命运 | 前世愧疚弥补 |
| 追妻火葬场 | 心疼/补偿 | 遗憾、失去才懂 |

### 拨弦频率

- 每500字至少要有一个情弦触动点
- 触动不一定是"爽"——期待、紧张、心疼、愤怒都是触动

## 拉扯节奏

### 上升节奏

```
铺垫（缓）→ 小冲突（紧）→ 小胜（松）→ 困境（紧）
→ 低谷（极紧）→ 顿悟/办法（爆）→ 反转（松中带紧）
```

### 下降节奏

爆点之后不立即回到高点，而是**留一段沉淀**——战斗后的伤、成功后代价、死者的遗物。

### 禁忌：一直升或一直降

- 一直升 = 情绪饱和 = 无高潮
- 一直降 = 读者压抑 = 弃书

## 情绪烈度

### 男频烈度要求

网文不是纯文学。**爽点要够狠、够具体、够当众、够绝。**

- 打脸要当众（围观者≥3人效果最好）
- 反转要干净（不能拖）
- 对手的反应要夸张但不过度
- 敢写极端反应（对方失态、围观哗然）

### 烈度对照表

| 烈度 | 肢体反应 | 语言反应 | 场景 |
|------|---------|---------|------|
| 1 | 微表情 | 语气冷淡 | 内心活动 |
| 2 | 肢体紧绷 | 一句话回应 | 日常对战 |
| 3 | 后退一步 | 质问 | 冲突升级 |
| 4 | 失态动作 | 当众骂人 | 正面打脸 |
| 5 | 崩溃反应 | 尖叫/哑口 | 高潮打脸 |

### 禁忌：温吞保守

"点到为止"是网文最忌讳的爽快处理方式。该虐虐透，该爽爽炸。

## 期待感管理

### 期待感公式

```
期待感 = 未知 × 赌注 × 频率
```

- **未知**：读者不知道结果是什么
- **赌注**：主角/角色在乎的结果
- **频率**：期待—释放之间的间隔

### 持续拉期待操作框架

1. 建立"接下来会怎样"的核心悬念
2. 用"差一点就得到，但你偏得不到"反复拉
3. 在即将解决时增加新变数（不是故意拖延，是逻辑上必然）
4. 释放后立即建立新期待

### 六种断期待模式与修复

| 断期待模式 | 触发原因 | 修复方法 |
|-----------|---------|---------|
| 过早解决 | 预期悬念10章内就解决 | 引出更深层悬念 |
| 突然跳脱 | 情绪切换太快无铺垫 | 加过渡段 |
| 设定崩塌 | 违反前面设定的发展 | 自检+FIX |
| 降智光环 | 对手突然变蠢 | 反派智商回归 |
| 主角圣母 | 强行原谅/道德绑架 | 动机合理化 |
| 节奏失控 | 连续N章无兴奋点 | 强制插入爆点 |

## 爽点释放节奏

### 爽点周期

| 周期 | 小爽点 | 大爽点 |
|------|-------|-------|
| 小周期 | 3-5章 | — |
| 中周期 | 15-20章 | 1次大爽 |
| 大周期 | — | 每30-50章一次 |

### 爽点类型

| 类型 | 爽感来源 | 写法要点 |
|------|---------|---------|
| 装逼打脸 | 地位逆转 | 反差要大、围观者要多 |
| 升级突破 | 进步感 | 用多维度对比强化 |
| 复仇碾压 | 因果报应 | 前世/前因后果要清楚 |
| 真相揭示 | 智力优越 | 读者后知后觉 |
| 感情推进 | 共情满足 | 含蓄中带甜 |
| 装备/收获 | 获得感 | 具体、不空 |

### 爽点密度禁忌

- 10章以内无爽点 = 读者弃书
- 每章都是爽点 = 情绪饱和
- 小爽+小爽 ≠ 大爽（大爽需要前置压抑）

## 起承转合节奏模型

| 位置 | 情绪 | 事件 | 写作要点 |
|------|------|------|---------|
| 起 | 平静→期待 | 触发事件 | 引入核心钩子 |
| 承 | 升温→紧张 | 冲突加深 | 障碍递进、信息展开 |
| 转 | 极紧→反转 | 重大转折 | 压抑的极限点 |
| 合 | 释放→平缓 | 解决/新开始 | 收束+建新钩子 |

## 环境交互法

### 以景写情

用环境细节暗示情绪：
- 主角紧张时 → 天气闷热/天色压抑
- 主角轻松时 → 风轻/鸟鸣
- 要爆发前 → 风停了/沉默了

### 环境变化=情绪转折

不直接写情绪，改环境：
```
❌ "他感到难过"
✅ "雨打在伞面上，像谁在用指尖敲。他没动。"
```

## 连载节奏管理

### 更新节奏

- 日更4000-6000字：保持期待但不卡文
- 每章结尾都有钩子
- 结构上 5-10 章一段故事弧

### 推荐节奏模板

```
[打] → [爽] → [过渡] → [埋伏笔] → [拉期待] → [打] → ...
```

循环。
