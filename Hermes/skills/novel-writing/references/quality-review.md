## 审查总览

### 审查频率

| 时机 | 审查内容 |
|------|---------|
| 每写完一章 | AI味检测 + 字数 + 章尾钩子 |
| 每5-10章 | 节奏 + 角色一致性 + 伏笔追踪 |
| 每卷结束 | 设定一致性 + 大纲完成度 |
| 全书完结 | 完结审查（撒花/收束） |

### 审查输出

每次审查产出：
1. 问题清单（按优先级排序）
2. 修复建议
3. 修复后的状态（待修/已修/暂保留）

## 五维评分体系

### 维度一：代入感（1-10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 三章以内读者"我即主角"，感官真实，情绪共振 |
| 7-8 | 大多数章节能代入，偶有上帝视角/解释腔 |
| 5-6 | 经常出戏，视角漂浮，情感不真实 |
| <5 | 读者完全无法代入（失败） |

### 维度二：节奏感（1-10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 张弛有度，包袱-释放节奏精准 |
| 7-8 | 大部分章节节奏好，偶有拖沓 |
| 5-6 | 连续3章以上平淡或连续紧张累 |
| <5 | 全书节奏失控（无起伏） |

### 维度三：信息密度（1-10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 每一章都有实质信息推进，无废章 |
| 7-8 | 大多数章节信息充实，偶有过场章略拖 |
| 5-6 | 信息注水，大量描写无信息量 |
| <5 | 严重水字数（失败） |

### 维度四：去AI度（1-10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 无任何AI痕迹，像人写的 |
| 7-8 | 偶有AI句式/比喻，不影响阅读 |
| 5-6 | AI味明显，多处禁句/万能比喻 |
| <5 | 严重AI味（失败） |

### 维度五：情绪弧线（1-10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 每节至少拨动一次情绪弦，有明确情绪起伏 |
| 7-8 | 大多数节有情绪拨动，偶有平淡 |
| 5-6 | 连续章节无情绪波动 |
| <5 | 全书情绪温吞（失败） |

### 最低标准

每个维度 ≥ 6 分为及格线。< 6 必须润色修复。

## AI味检测清单

写完后逐条检查：

- [ ] 无 `……` 标点
- [ ] 无 `——` / `--` 标点
- [ ] 无"命运齿轮/如潮水/像XX一样"等万能比喻
- [ ] 无"他不知道的是/殊不知/多年以后"
- [ ] 无"像下定了决心""仿佛明白了什么"
- [ ] 无"眼眶泛红/心猛地一沉"
- [ ] 无先否定再肯定的翻转句式
- [ ] 无元叙事词（"第X章""上一章""伏笔"）
- [ ] 无通用模板式描写（"微风轻拂""阳光洒落"）
- [ ] 对话个性化（遮住角色名仍能认出是谁说的）

### 自动化检测方法

逐章扫描以下命中频率：
- `……` / `——` / `--` 出现次数 = 0
- `像` `如` `仿佛` 比喻词 ≤ 3次/万字
- `不禁` `令人` `似乎` 出现频率（>2次/万字需检查）
- 连续排比≥3次 → 打散

## 字数与节奏自检

### 字数铁律

| 类型 | 最低标准 |
|------|---------|
| 网文章节 | ≥ 2000字（建议≥3000字） |
| 等级网文每章 | ≥ 8000字（含断章线以上高密度内容） |
| 短篇章节 | ≥ 1000字 |

### 节奏自检

每章问以下5个问题：
1. 本章节奏是否和上下文章节有起伏变化？
2. 高潮章前面的铺垫是否足够？
3. 短句/长句分布是否过于单调？
4. 是否有某一段落连续100字以上的大段描写/叙述？
5. 章尾钩子是否自然？

## 角色一致性检验

### 每5-10章检查一次

| 检查项 | 标准 |
|-------|------|
| 角色语言风格 | 和语言风格档案匹配 |
| 角色实力 | 和角色状态表一致 |
| 角色关系 | 和关系图一致 |
| 角色动机 | 行为符合当前动机 |
| 角色成长弧 | 有条不紊地发展 |
| 角色OOC | 行为是否有违性格（除非有原因） |

### OOC自检方法

选中角色的每一个行为，问：
1. 角色档案会支持他这么做吗？
2. 如果支持，理由是什么？
3. 如果不支持，要么改行为要么改档案

## 设定一致性检验

### 每卷检查一次

| 检查项 | 方法 |
|-------|------|
| 力量体系 | 各角色实力是否自洽 |
| 地理关系 | 地图位置是否矛盾 |
| 历史事件 | 前后时间线是否一致 |
| 设定细节 | 道具/势力/规则前后是否矛盾 |
| 因果 | 事件链是否闭合 |

### 设定checklist格式

```markdown
## 设定checklist

### [世界观/力量体系]
- 规则：最多不多于N项
- 代价：每次使用XXX代价
- 上限：不超过YYY
- 违反规则的章节/位置：无

### [角色X的设定]
- 核心标签：YYY
- 特殊能力：ZZZ
- 限制：WWW
- 成长节点：第N章 → 第M章
```

## 伏笔与钩子追踪

### 伏笔追踪表

```markdown
## 伏笔追踪表

| 伏笔ID | 埋设章节 | 内容 | 预期回收 | 实际回收 | 状态 |
|-------|---------|------|---------|---------|------|
| F001 | 第3章老者一句话 | "那枚玉佩不是你的" | 第50章 | 第48章 | ✓ |
| F002 | 第5章捡到铜钱 | 铜钱背面有暗记 | 第80章 | 未收 | ⚠ |
| F003 | 第10章 | XXX | 第30章 | — | 待收 |
```

### 回收优先级

| 状态 | 优先级 | 操作 |
|------|-------|------|
| 已收 | — | 无 |
| 待收但期限将至 | 🔴 | 立即安排回收 |
| 已错过回收点 | 🟡 | 找新方式回收或解释 |
| 长期伏笔 | 🟢 | 继续等待最佳时机 |

## 章节通读检查

### 通读标准

每写完5-10章通读一次：
1. 一口气读完，不做任何修改
2. 标注读不下去的点
3. 标注出戏的点
4. 标注无聊的点
5. 标注疑点/逻辑断点

### 通读后的处理

| 标注类型 | 优先级 | 处理 |
|---------|-------|------|
| 读不下去（卡住） | 🔴 | 立即修 |
| 出戏 | 🔴 | 立即修 |
| 逻辑断点 | 🟡 | 尽快修 |
| 无聊 | 🟡 | 考虑增加冲突/悬念 |
| 小问题 | 🟢 | 下轮处理 |

## 完结检查清单

全书完结时检查：

- [ ] 主线核心冲突是否完全解决
- [ ] 至少80%以上的伏笔已回收（未收的有合理原因）
- [ ] 主要角色成长弧是否完整
- [ ] 世界观核心秘密是否揭示
- [ ] 番外/续集钩子是否留下
- [ ] 最终章是否有高质量的余韵
- [ ] 无严重设定崩塌/逻辑断点
- [ ] 读者意犹未尽感（不是烂尾感）

## 润色手法

### 第一遍：宏观润色

- 删掉不影响情节的段落
- 缩短过长的过渡/描写
- 保证每段/每章有推进感

### 第二遍：微观润色

- 替换万能比喻
- 画面感不足的段落加细节
- 对话去信息倾倒
- 标点符号修正

### 第三遍：声韵润色

- 通读全篇（建议朗读/脑内朗读）
- 标注拗口/不流畅的句子
- 调整句长节奏
- 检查排比/对偶是否做作

### 润色铁律

1. 不是"润色越多越好"
2. 读起来没阻滞的地方没不动
3. 润色时不动情节、不动角色内核
4. 每次润色后重新通读验证
