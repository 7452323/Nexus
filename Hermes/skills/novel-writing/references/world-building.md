## 三维交织世界观

### 三维度定义

| 维度 | 定义 | 举例 | 核心问题 |
|------|------|------|---------|
| **物理层** | 世界的空间、时间、力量体系 | 地理环境、修炼等级、宇宙结构 | "这个世界怎么运转？" |
| **社会层** | 阶层、势力、权力关系 | 家族/宗门分布、规则/法律、经济系统 | "人和人之间怎么玩？" |
| **隐喻层** | 哲学主题、人性探索、深层命题 | "何为正道""宿命与选择""阶级跃迁" | "这故事在讨论什么？" |

### 三者关系

- **物理层**是舞台：读者能感知的具象世界
- **社会层**是冲突源：人物之间的张力来自社会结构
- **隐喻层**是深度：让故事超越爽文、有回味空间

### 三维交织检查

每个情节/设定至少应该在两个维度上有意义：

```
例：主角考入宗门
→ 物理层：宗门是什么等级？修炼资源差异？
→ 社会层：原家族地位如何变化？宗内派系？
→ 隐喻层：血统论 vs 后天的努力？
```

## 世界观层次设计

### 信息分层法

不要开章就把世界观全盘托出。按以下层级逐步解锁：

| 层级 | 何时透露 | 内容 |
|------|---------|------|
| L1 表面 | 开篇就能感知 | 基本世界规则、人物身份 |
| L2 结构性 | 10-30章揭示 | 社会结构、势力分布、历史背景 |
| L3 隐藏层 | 50%以后揭示 | 世界真相、终极秘密、反派动机 |
| L4 隐喻层 | 全程渗透+结局揭示 | 哲学命题、主题命题 |

### 世界观的"冰山原则"

设定的90%不直接进正文，但在你脑子里——这样世界感才真实，写出来才自然。

## 卖点提取

### 一句话卖点

小说的核心吸引力，用一句话说清：

```
格式：[主角身份] + [目标/冲突] + [独特钩子]

例：
"废物少年偶得上古丹方，从此逆天改命、踏破九重天"
"重生到被退婚前一天，她决定不再爱任何人"
"穿越成太监，却发现皇帝是女的"
```

### 预期记忆点

读者看完这本书后会记住什么？
- 一个角色特征？
- 一句金句？
- 一个情节反转？
- 一种世界观设定？

### 卖点三要素

| 要素 | 核心 | 举例 |
|------|------|------|
| 代入感来源 | 主角让读者代入的点 | 被看不起/贫穷/被冤枉 |
| 期待感来源 | 读者想看的东西 | 反杀/揭密/升迁 |
| 独特性来源 | 和其他同类型的差异点 | 世界观/金手指设定 |

## 金手指设计要点

### 金手指优先级

1. **信息挂**最优（先知/系统/重生记忆）——不易失控，爽感来源于信息差
2. **加速升级挂**（时间加速/加速修炼）——节奏可控
3. **物品调用挂**（储物空间/藏经阁）——容易让主角无限变强，需严格限制

### 金手指设计铁律

1. 规则简单一句话能说清
2. 功能与升级规则清晰
3. 必须有代价/限制（不是白给的）
4. 随主角变强而进化（绑定成长线）

### 金手指升级路线

```
阶段1：小功能 → 建立信任 → 解开限制
阶段2：多功能组合 → 战略级应用 → 升级规则变化
阶段3：质变/解锁隐藏功能 → 与核心冲突绑定
```

### 代价设计

| 代价类型 | 举例 |
|---------|------|
| 资源消耗 | 每次使用耗费大量灵石 |
| 时间冷却 | 每72小时才能用一次 |
| 身体负荷 | 使用后需要恢复/伤害身体 |
| 暴露风险 | 使用会暴露能力被强者发现 |
| 心智侵蚀 | 使用越多次越容易被控制 |

## 升级感设计

### 多角度强化对比（升级感的真正来源）

升级不是只有"等级突破"，而是**多维度变化的综合感受**：

| 维度 | 升级前 | 升级后 |
|------|-------|-------|
| 实力 | 被忽视/被动 | 被忌惮/主动 |
| 社交 | 无人理睬 | 有人攀附/巴结 |
| 资源 | 匮乏/拼凑 | 充裕/交易 |
| 信息 | 被蒙蔽 | 主动获取 |
| 社交圈 | 底层小人物 | 接触到上层 |
| 心态 | 隐忍/愤懑 | 自信/从容 |

### 反向设计升级感

不只写"升级后怎样"，更写"过去不敢做的事现在敢做了"：
- 过去：被人瞪一眼 → 怒不敢言
- 现在：瞪回去 → 对方心虚移开目光

### 名望与阶层的辩证关系

不是等级高了名望就自动高。名望来源于：
- 事迹传播（做了什么被别人看到）
- 第三者背书（权威人物/势力的认可）
- 持续稳定展示（不是一次性的）

### 节点设计法

在关键节点（转折点/高潮点）设计特定升级：

```
节点A：心境提升（不是等级，而是心态质变）
节点B：实力突破（数值可感知的升级）
节点C：地位跃迁（被社会认知的变化）
节点D：圈子扩大（接触到更高层次的存在）
```

## 换地图处理技巧

### 换地图的五个步骤

1. **预警**：N章前提示新地图即将出现
2. **关口**：一次性场景完成空间转换
3. **冲击**：新地图带来的首次冲击（强者/势力/新规则）
4. **适应**：主角用现有技能在新地图立住
5. **崛起**：在新地图建立新的社会地位

### 新旧地图衔接

- 将旧地图的人物/势力带入新地图
- 回收旧地图在新地图才生效的伏笔
- 旧地图的敌人可能在新地图有背景/上级势力
