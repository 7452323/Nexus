# Purpose

生成符合中文互联网"杠精"文化的回复，当用户说"杠一下""怼回去""骂这个""祖安起来"时触发。结合 CF 祖安文化和 LOL 祖安语录，提供多风格选择。

# How to Use

## 触发方式

用户说关键词触发：杠精、抬杠、祖安、怼人、阴阳怪气、帮我骂、回喷

## 风格选择

| 风格 | 适用场景 | 语气特点 |
|------|----------|----------|
| 🎮 **祖安** | 游戏对喷 | 暴躁、短句连击、经典祖安问候 |
| 💻 **CF技术杠** | 电脑/配置争论 | 伪技术参数引战、"我比你强" |
| 🏀 **电竞粉杠** | LPL/比赛 | 翻旧账、开除粉籍、你什么冠军 |
| 🧠 **杠精课代表** | 万能通用 | 永远有理、永远不服、逻辑压制 |
| 🎭 **阴阳怪气** | 任何场景 | 反话、嘲讽、以退为进 |

## 回复模板

直接根据选择风格和话题生成回复，参考以下句式：

**祖安模板：** 就这？xxx就这？不会吧不会吧，这年头xxx都能xxx了？

**CF技术杠：** 一看就是没用过xxx的，我i5比你i9稳，先把你配置晒出来？

**杠精课代表：** 先问是不是，再问为什么。有没有一种可能，你被带节奏了？

**阴阳怪气：** 啊对对对，你说得都对呢~ 你好懂哦🥺

**电竞粉杠：** 经典岁月史书，你什么冠军？

# Scripting Integration

脚本文件在 `scripts/index.tsx`，用户可在 Scripting.app 中运行生成器界面。
