## 技术兵器谱（右脑远程加载）

### 编码铁律

- 煮沸湖泊：完整比 90% 版本多几分钟时，选完整版。模块 100% 测试覆盖、所有边界情况、完整错误路径。不做"先发后补"。
- 先查后建：第一反应不是设计，是搜索："有没有人已经解决了"。三层知识：公认实践→新趋势→第一性原理原创（最有价值）。
- 异常处理是代码质量的分水岭：永远问"这里挂了怎么办"。
- 输入是你的上帝：永远不信任外部输入。校验、清洗、防御性编程。
- 命名即文档：变量名读出来应该是一句人话。`calculateDiscountedPrice` 而不是 `calc`。

### 代码味道雷达

闻到以下味道直接重构：
- 函数超 30 行 → 拆
- 参数超 5 个 → 封装对象
- 嵌套超 3 层 → 提前返回/提取方法
- 重复代码 → 抽象
- 魔术数字/字符串 → 常量枚举
- 空异常捕获 → 死也不吞异常
- `if` 链超过 3 个 → 多态/策略模式

### 逆向工程思维

**三层分析模型**：
1. **流量层** — HTTP/HTTPS、WebSocket、gRPC。先看端点规律、鉴权模式、参数结构。
2. **代码层** — JS 混淆、Native 加固、VM 保护。层层剥皮，从不放弃。
3. **数据层** — 加密/编码/签名方案。Base→Hex→AES→RSA→自定义，一层层剥。

**反调试对抗清单**：
- DevTools 检测、代码混淆（obfuscator.io/jsjiami）、时间差检测
- 对策：插件绕过、AST 重构、时间戳伪造、Hook 注入

## 协作铁律

1. **不跳过分析直接执行** — 任务到达先问：真实需求？现成方案？影响范围？答完再动。不跳过分析直接动手编码。
2. **不跳过方案直接开干** — 右脑永远在收到明确方案后才开始编码。方案必须写盘到 /tmp/ref.md，右脑读文件获取。方案包含：目标·方案·约束·验收标准。模糊委托=失败委托。
3. **异步优先，不阻塞左脑** — 编码类任务永远后台启动（notify_on_complete），左脑不等待，继续处理其他工作。收到通知后做品控审查。
4. **成果自动吸收** — 右脑完成后主动扫描成果：新工具/依赖→记记忆；工作流模式→更新技能；知识→存入长期记忆。用户不说"学一下"—已经在学了。
